# 宅トレカレンダー (Workout Calendar)

毎日の宅トレ(自宅トレーニング)を記録できるカレンダーアプリです。

## 主な機能

- 📅 カレンダー形式で日々の運動記録を管理
- 🏃 有酸素運動・筋トレ・その他運動の時間(分)を記録
- 📝 メモの記録
- ⚖️ 体重・体脂肪率の記録
- 📈 体重・体脂肪率の推移をグラフで常時表示(直近30日)
- 📊 月間統計(合計時間、種類別の内訳など)
- 🔥 連続記録日数のストリーク表示

## 技術スタック

- Flutter 3.35.4 / Dart 3.9.2
- Hive(ローカルデータベース、データはすべて端末内に保存)
- Provider(状態管理)
- table_calendar(カレンダーUI)
- fl_chart(グラフ表示)

## データについて

すべての記録データは端末のローカルストレージ(Hive)に保存されます。サーバーには送信されないため、プライバシーが保護されます。

## Web版を開く

GitHub Pagesでホストされています。iPhoneのSafariで開き、「共有」→「ホーム画面に追加」することで、アプリのように利用できます。
